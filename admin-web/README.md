# Clinic Platform Admin

لوحة ويب منفصلة لإدارة منصة العيادة، وليست تطبيق Android ثالث.

## الوظائف
- عرض كل العيادات وحالة الاشتراك.
- تنبيه العيادات التي ينتهي اشتراكها خلال 7 أيام.
- تعليق/إلغاء/استعادة اشتراك ما زالت مدته المدفوعة سارية.
- تأكيد أو رفض طلبات الدفع.
- تسجيل دفعة يدوية وتمديد الاشتراك.
- عرض سجل آخر الدفعات مع التصفية بالحالة.
- عرض الإيراد المؤكد بالجنيه السوداني من ملخص قاعدة البيانات.
- سجل كامل لتغييرات الاشتراك.

## أول حساب إدارة
1. أنشئ حساب Auth من شاشة اللوحة أو سجّل الدخول بحساب موجود.
2. إذا لم يكن هناك Platform Admin بعد، تظهر شاشة تهيئة أول مدير.
3. أدخل رمز التهيئة الذي تم إنشاؤه خارج المستودع.
4. بعد نجاح التهيئة يصبح الحساب أول `platform_admin` ويتعطل الرمز نهائيًا.

لا تضع رمز التهيئة في GitHub أو في ملفات الواجهة.

## الأمان
- الواجهة تستخدم Supabase Publishable Key فقط.
- كل العمليات الحساسة محمية بـ RLS وRPC وتحتاج عضوية `platform_admins`.
- إنشاء حساب Auth وحده لا يمنح صلاحية الإدارة.
- تهيئة أول مدير محمية برمز لمرة واحدة محفوظ كـ SHA-256 داخل schema خاص غير مكشوف للـData API.
- لا يوجد Service Role أو Secret Key داخل الواجهة.

## التحقق
GitHub Actions يشغل `node admin-web/check.js` عند كل تعديل للتأكد من سلامة JavaScript وربط عناصر الواجهة وعدم إدخال مفاتيح سرية.
