# Clinic Platform Admin

لوحة ويب منفصلة لإدارة منصة العيادة، وليست تطبيق Android ثالث.

## الوظائف
- عرض كل العيادات وحالة الاشتراك.
- تعليق/إلغاء/استعادة اشتراك ما زالت مدته المدفوعة سارية.
- تأكيد أو رفض طلبات الدفع.
- تسجيل دفعة يدوية وتمديد الاشتراك.
- سجل كامل لتغييرات الاشتراك.

## الأمان
- الواجهة تستخدم Supabase Publishable Key فقط.
- كل العمليات الحساسة محمية بـ RLS وRPC وتحتاج عضوية `platform_admins`.
- إنشاء حساب Auth وحده لا يمنح صلاحية الإدارة.
- أول حساب إدارة يُضاف مرة واحدة إلى `public.platform_admins` من إدارة المنصة.
